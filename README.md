# tamoai-cloud-agents
TamoAI is a unified, responsive Netlify cloud platform hosting 3 always-on AI agents on dedicated Linux VMs: Fuse (Meta Muse clone with a shared live browser, Sentinel permissions, Realtime Avatar &amp; Fuse Charm), Pots (OpenAI Dots clone on Tamo-6 Astra with Slack/Teams sync), and Gawk Bot (xAI Grok Bot shared-VM computer-use AI teammates).
