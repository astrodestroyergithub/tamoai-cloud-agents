# TamoAI Cloud OS — Unified Parent Platform (Fuse, Pots & Gawk Bot)

Production-ready static & SPA bundle engineered for instant deployment on **Netlify**.

## Included Always-On Cloud AI Agent Clones
1. **Fuse (Meta Muse Clone)**:
   - Runs on **Fuse Spark** inside an isolated **Fuse Secure VM** (8GB RAM Linux + Shared Live Cloud Browser).
   - Includes **Intervene / Take Control** live browser toggle, **Sentinel Permissions System** (Read / Write / Ask First / Blocked + Amazon retail guardrail notice), **Realtime Avatar Video Mode**, custom Python tool builder, dedicated agent email (`nova.fuse@agent.tamo.ai`), Commerce Partners, and the **Fuse Charm** wearable companion widget.
2. **Pots (OpenAI Dots Clone)**:
   - Runs on **Tamo-6 Astra** with per-Pot **Cloud Computers** + time-bounded **Local Computer Access** bridge.
   - Includes **Activity View** (Read-Only Background Research, Pending Approvals with Custom Rules, Open Questions), multi-channel context synchronization across **TamoChat, Slack, and Microsoft Teams**, 4,000+ App Plugins, and **Specialist Pots** aligned with **Microsoft Agent 365** governance.
3. **Gawk Bot (xAI Grok Bot Clone)**:
   - Runs on **Gawk 4.6** across a shared **TamoCursor Cloud Linux VM** where Personal and Team Bots share browser sessions, filesystems, and terminal state.
   - Includes the **3-Path Authentication Engine** (OAuth Connectors, Human Sign-In Takeover with Okta 2FA & WebAuthn Passkey forwarding, and Masked Secret Requests), **LLM Auto-Review Classifier**, and weekly token expenditure telemetry.

## Deploying to Netlify
- **Option A (Drag & Drop)**: Drag the unzipped folder (or `tamoai-cloud-agents-netlify.zip`) directly into [https://app.netlify.com/drop](https://app.netlify.com/drop).
- **Option B (Git / CLI)**: Run `netlify deploy --prod --dir=.` from the root of this bundle. `netlify.toml` and `_redirects` are pre-configured.
